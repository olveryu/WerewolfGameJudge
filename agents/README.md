# Agent configuration (canonical source)

Edit only `AGENTS.md`, `agents/path-rules/*.md` and `.agents/skills/*/SKILL.md`, then run
`pnpm run sync:agents`. Everything under `.github/instructions/`, `.cursor/rules/`, `.claude/skills/`
and the root `CLAUDE.md` / `GEMINI.md` / `MUSE.md` is generated.

Full reference and maintenance SOP: [docs/agent-config.md](../docs/agent-config.md).
