# 房间会话生命周期

## 所有权

`CloudflareGameSessionFactory` 为应用持有一个 `ActiveRoomSessionOwner`。目录中的游戏模块持有 `LazyRoomSession` 类型化句柄，只有 `connect` 取得独占租约后才创建 `RoomSession`、Cloudflare transport 和平台连接监听器。

已有活动房间时，第二次进入明确失败，调用方必须先完成既有退出流程。不会自动把仍在游戏中的玩家移出房间。

## 释放与恢复

退出依次取消订阅、销毁实际会话及连接、释放租约，再发布 idle。稳定句柄保留 UI 订阅和游戏事件处理器，新实例继承上一实例的 epoch，旧的 prepared command 不能命中新房间。

连接失败保留当前房间身份供界面展示错误和退出；取消进入则释放资源。重新进入分配新实例，断线重连仍由当前实例的既有状态机负责。

账号页面的跨游戏 capability 投影继续用于渲染，互斥由连接前租约执行，不依赖渲染时才发现冲突。游戏静态导航、首页和产品贡献仍在目录中注册；未重写游戏运行时或命令恢复协议。
