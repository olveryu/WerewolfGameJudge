# 房间手牌与信息区：最终效果说明

本文只描述玩家最终看到的界面与交互体验，不包含技术方案、代码或实施步骤。以下为目标效果，不代表所有游戏均已上线此界面。

## 整体布局

房间由上至下分为四个区域：

1. **房间标题**：游戏名、房间信息、右上角个人设置入口。
2. **本局信息**：开局前展示配置，开局后展示局势，结束后展示结果。
3. **玩家座位**：查看玩家、辨认当前行动对象、选择目标。
4. **底部手牌**：当前行动、常用查询入口、手册与房主管理。

本局信息沿用原有配置展示的位置，不额外增加一条重复的信息栏。座位房间中，状态和配置或局势固定在座位上方，座位区域可以滚动。状态卡沿用房间主题：小字显示阶段上下文，当前状态居中突出，下方只保留当前玩家需要的简短提示；较长内容自然换行。终局以胜负或最终结果为主。座位名单整组居中，需要时换行；不必常看的长名单放在详情里。

各游戏的现有状态提示统一上述阅读层次，任务轨道、比分和其他专属信息按游戏需要展示；专属游戏界面不凭空增加重复状态卡。状态卡只读，详情和行动继续使用各自已有入口。

状态和角色配置默认完整显示，不自动收起。阿瓦隆和秘密希特勒开局后的信息区与座位一起滚动，底部手牌保持可用；其他游戏维持原来的布局。

## 专属游戏界面里的菜单

你画我猜、你画我猜接龙、轮流讲故事、一眼成对，在座位阶段和结束阶段可以直接展示手牌。进入专属游戏界面后，保留原来的画布、编辑器或实时牌桌，不常驻功能手牌。

- 右上角原来的房主管理入口改为所有玩家可见的「菜单」。
- 点击后从房间下沿露出同样样式的手牌，不增加包围牌组的面板。
- 玩家看到：返回、手册、本局配置。
- 房主看到：返回、手册、本局配置；当前阶段允许重新开始时，另有相应操作。
- 最左侧「返回」牌收起菜单，不另设关闭菜单按钮。
- 手册仍打开子手牌；子手牌最左侧「返回」回到菜单手牌，不直接退出菜单。
- 在菜单或菜单里的手册点任一操作牌（玩法、本局配置、重新开始等），菜单立即收起。
- 重新开始使用危险红，执行前明确确认并说明后果。
- 收起菜单后保留原来的输入与编辑内容。打开菜单不暂停对局，倒计时和其他玩家的行动继续。
- 玩法中的绘画工具、发送、准备、匹配图案等操作仍留在专属界面，不搬进菜单。
- 结束后取消右上角的重复菜单入口，底部直接显示手牌；故事、画廊或排行榜保留在主区，能够完整翻阅，不被手牌遮挡。
- 轮流讲故事结束后的主手牌为本局复盘、本局配置、手册；房主另有房主管理。房主管理内提供「重新开始」，执行前明确确认。
- 揭晓前重新开始会中止本局，不发正常完成奖励，清除本局内容并直接回准备；确认时明确说明。两款接龙的完成奖励仅在进入揭晓时结算，揭晓后重新开始不撤销已结算奖励。

### 逐段揭晓：保留同步观看体验

- 逐段揭晓仍属于游戏进行中，不提前切换为结束后的自由翻阅界面，也不常驻结束手牌。
- 主区保留原来的故事或画作揭晓体验，全员跟随房间的共同进度；未揭晓的内容不能通过翻页、复盘或其他入口提前查看。
- 房主的上一项、下一项、播放／暂停、全部揭晓等当前可用控制留在作品附近，不藏进菜单。
- 右上角继续提供所有玩家可见的菜单，打开后显示返回、手册、本局配置。轮流讲故事的揭晓阶段现有的操作限制保留。
- 打开菜单不暂停揭晓，收起后回到房间当前的揭晓进度。
- 全部揭晓并进入结束阶段后，才开放完整作品的自由翻阅，并在底部直接显示结束手牌。「全部揭晓」执行前保留明确确认。

## 本局信息随阶段变化

| 阶段       | 上方区域                                         | 主手牌                 |
| ---------- | ------------------------------------------------ | ---------------------- |
| 等待开局   | 完整角色配置与必要的模式信息；角色可点击查看说明 | 不重复出现「本局配置」 |
| 游戏进行中 | 当前局势、进度，以及适用的公开记录入口           | 直接出现「本局配置」   |
| 已结束     | 最终结果，以及适用的公开记录入口                 | 继续保留「本局配置」   |

已分配身份但尚未开始游戏，仍属于开局前。

### 开局前：进房就能了解这局怎么玩

- 角色构成直接可见，不要求玩家先打开手册或某张手牌。
- 保持紧凑排列，常规角色名称下每行可展示四种角色，不退回宽松的大卡片列表。
- 配置展示角色种类与数量，不展示角色被分配给了谁。
- 点击角色可查看该角色说明。
- 人数、模式、词语分类等信息按游戏需要展示，不保留无内容的栏目。

### 开局后：局势取代静态配置

- 不再整局铺开完整角色列表。
- 优先展示此刻有用的公共信息，不重复堆叠阶段大标题、说明段落与底部提示。
- 进度与记录跟随游戏内容变化；没有公开记录的游戏不出现空的记录入口。
- 私人身份、词语和秘密选择不会混入公共信息区。

### 各游戏的信息重点

| 游戏       | 信息区内容                                                         |
| ---------- | ------------------------------------------------------------------ |
| 狼人杀     | 当前昼夜阶段；警长竞选期间的环节、进度与公开记录；竞选结果         |
| 阿瓦隆     | 五轮任务轨道、当前任务与提案状态、适用的提交进度和公开记录         |
| 秘密希特勒 | 两条政策轨道、选举失败计数、当前政府信息和公开记录                 |
| 谁是卧底   | 开局前的人数、白板模式、词语分类与角色构成；开局后的当前公共状态   |
| 瞎掰王     | 开局前的人数与角色构成；选词等准备状态，以及需要玩家知道的准备异常 |

各游戏保持相同的信息位置与阅读层次，但不强求使用同样的轨道、栏目或标题。

阿瓦隆的任务轨道下方保留本轮组队次数轨道，标出否决、当前和最后一次自动通过；结束后不高亮当前组队。秘密希特勒的政策格可打开规则说明，选举失败三格轨道中的第三格标为混乱。两者优先显示当前行动，轨道后只放最近的公开结果，完整记录仍从手牌打开。五秒结果展示期间阻止其他交互，结束后恢复原有面板和草稿。

## 手牌的外观

- 手牌直接位于房间下沿，没有包住整副手牌的边框、底板或抽屉。
- 不显示「展开手牌」按钮，也不在牌上方重复显示当前手牌组的可见标题。
- 所有牌在同一排叠放，不分成主要操作一排、次要操作一排。
- 每张牌都能被辨认和点击，不需要横向拖动才能找到后面的牌。
- 牌身有很大一部分沉在房间下沿之外，不完整露出整张牌。
- 图标与牌名位于露出的部分，不把必要文字藏在下沿。
- 鼠标悬停或键盘聚焦时，对应牌抬起并突出。
- 触屏点击直接进入对应操作，不要求先点一次展开、再点一次执行。
- 牌面保持紧凑，只有必要图标与名称，不附带类别标签、解释性副标题或重复提示。

### 颜色

| 操作类型                                         | 配色   |
| ------------------------------------------------ | ------ |
| 玩家游戏行动                                     | 蓝色系 |
| 查询，包括身份、复盘、手册与本局配置             | 绿色系 |
| 主持流程，包括房主管理、分配角色、开始游戏和授权 | 紫色系 |
| 危险操作，包括重新开始和自爆结束竞选             | 红色系 |

普通类别使用浅色牌面和较深的同色文字、图标、边框；颜色由操作本身决定，不由所在手牌或主次决定。返回牌固定最左，其余按蓝色玩家行动、绿色查询、紫色主持流程、红色危险操作分组；同色的可用牌在前、不可用及提交中牌在后，各自保留原优先级，状态变化立即重排。

不可用牌保留浅同色、虚线边框和牌名，锁图标替换原功能图标；点击后在牌附近显示原因五秒，可重复查看。没有具体原因时显示「当前暂不可用」，不猜测原因。提交中显示转圈，不执行点击。

狼人杀主持手牌中，「昨夜信息」和「授权玩家查看」可用状态相同时，前者排在前面；可用状态不同时遵循同色可用牌优先。

图标按操作含义区分，例如确认用勾、取消用返回箭头、查看用眼睛；保留文字，不只靠颜色或图标传达含义。

## 手牌的内容与层级

### 主手牌

- 当前阶段适用的行动直接出现；跳过、撤回等可用行动与其他行动同排。
- 开局后的「本局配置」直接位于主手牌，不藏进手册或房主管理。
- 「分享房间」位于所有人的主手牌，只在开局前显示，包含发牌后尚未开始的阶段；不放进房主管理或房间号旁。
- 「手册」是一张牌；房主额外拥有「房主管理」牌。
- 房主仍保留自己的角色行动，不因管理身份而被切换成另一套主界面。
- 手牌内容随阶段和身份变化，不把所有阶段的操作同时堆出来。
- 狼人杀发牌前直接显示「提建议」或「修改建议」；有建议时才额外显示「查看建议」。
- 正式版需按游戏、阶段、角色和权限核对现有操作，不把原型示例当作完整清单。最大手牌场景下，每张可用牌的名称和点击区域仍应完整可用。

女巫兼房主的行动阶段示例：主手牌显示「女巫行动」、查看身份、本局配置、手册、房主管理；进入「女巫行动」后再显示当前可用的解药、毒药、不用药等选项。这是具体场景示例，不是所有游戏的固定牌数。选项按真实规则提供，不逐张标待办。

### 子手牌

- 点击「手册」，原位置换成玩法、攻略、笔记等查询牌。
- 点击「房主管理」，原位置换成当前阶段可用的管理牌。
- 子手牌替换主手牌，不在主手牌上方再叠一排。
- 「返回」本身也是一张牌，位于最左侧，回到上一层手牌。
- 在任何子手牌（手册、房主管理、角色行动）点一张操作牌，立即回到主手牌；确认框、选座和弹窗都在主手牌上进行，取消也停在主手牌。只有打开子手牌的入口牌和「返回」不算操作牌。
- 不在子手牌上方另外摆一个返回按钮或重复的「手册」标题。
- 角色当前有多个行动选项时，主手牌用一张角色行动入口，进入后展示对应子手牌；只有一个行动选项时仍直接显示。需要行动时入口或单张行动牌标待办；可选或已完成的行动不标，子手牌里的具体选项也不重复标待办。
- 选座子手牌只保留该流程的操作，不重复带入主手牌已有的「查看身份」。固定人数的技能选满即弹确认，不放底部确认牌；人数可变的技能保留底部确认入口。具体取消行为见下文。
- 选座确认在弹窗内提交：只有弹窗的确认按钮转圈，提交不携带手牌命令键；手牌上的逃生牌和其他命令牌一律锁住，原因为「有操作正在提交」。选座提交不借用任何手牌的身份。（2026-11-21 用户确认）

### 本局配置

- 点击后查看本局的完整角色构成与模式信息。
- 弹窗复用开局前的信息区配置内容：相同的配置数据、模式信息和角色列表，只换外壳，不另做一套展示。板型建议等操作不随配置内容带进只读弹窗。
- 点击角色沿用原有的角色详情弹窗，不在配置窗里切换成详情页。关闭角色详情后回到刚才的配置位置；只显示角色说明，不揭示其他玩家的身份。
- 这是所有玩家的只读查询入口，不是修改配置入口。
- 房主修改配置仍属于房主管理，与「本局配置」明确区分。

### 房主管理与个人设置

- 房主管理只展示当前阶段适用的操作。
- 房主有待办时，房主管理入口显示「待行动」，不显示数量；进入后标出对应事项。被阻塞的待办也保留标记，入口保持可打开，并说明阻塞原因。
- 音乐设置只在开局前出现，包括已分配身份但尚未开始的阶段；进行中和结束后均不出现。
- 个人与账号设置不放在主手牌或舞台菜单手牌；右上角入口及其弹窗保留。

### 待办规则

- 待办提醒当前需要本人完成、否则相应流程不能继续的事项；由各游戏按真实阶段、角色、权限、完成状态和前置关系声明，不从颜色、主次或按钮名称推断。
- 待办以牌顶居中的同色「待行动」文字标记，不遮挡牌名或功能图标；同样向辅助技术说明。颜色、危险性和待办是独立维度。
- 有依赖时先显示前置待办，完成后再提示下一项；互不依赖的事项可同时显示。例如房主也是玩家时，先提示本人首次查看身份，完成后再提示主持管理里的开始游戏，即使仍在等其他玩家。
- 待办是需要去处理的提醒，不给流程内每次点击重复贴标签。首次查看身份和主持管理中的分配角色可标待办；进入具体选座流程后，确认和取消不重复标。
- 不可用但仍需完成的事项保留待办和原因，例如人数不足时的分配角色，或未获授权时的玩家复盘。提交中、失败及恢复后的状态按实际结果更新，不能因点击或请求失败就算完成。
- 被其他真人的身份查看阻塞时，房主的开始游戏仍是待办，并显示等待进度。黑死病模式全员看完后由真人法官主持、没有开始按钮；等待期间只显示进度，不虚构待办。
- 房主代打机器人时，个人行动待办跟随当前代打座位；切回自己后恢复自己的事项。等待机器人查看身份时，可提示房主具体座位，不泄露身份。「标记机器人已查看」是可选快捷操作，不单独标待办。
- 游戏内操作直接呈现在舞台或同一组平等选项时，不额外创造待办牌。例如舞台的画画、猜词保持原有操作方式；女巫的用药选项进入角色子手牌后不分别标待办。
- 各游戏准备失败时，如果房主必须处理才能继续，主持管理显示一个待办，内部说明原因和实际可选处理方式；互斥方案不算作多个待办。

### 重新开始

- 九款游戏统一只保留「重新开始」，确认后清除本局并回到准备阶段，保留座位和配置，由房主决定何时开始下一局；不再提供直接开始新局或重新发牌的第二个入口。
- 游戏进行中也使用「重新开始」。确认内容按游戏说明实际影响，包括中止本局、不结算奖励以及会清除的本局内容；不声称存在未实现的保存功能。
- 进行中重新开始不要求玩家先查看已有记录；确认后直接清局回准备，不承诺中止后仍能查看被清除的复盘或作品。
- 正常终局即使房主已完成自己的待办，仍须确认并说明复盘可能无法再查看。有未完成事项时只提醒房主自己的事项，不列出或提示其他玩家的完成情况；确认后允许继续，不强制完成复盘。
- 瞎掰王的「重新抽词」用于换题，不是重新开始，保留为可选操作。

### 终局复盘

- 狼人杀、阿瓦隆、秘密希特勒、谁是卧底和瞎掰王正常结束后，房主和入座玩家各自查看一次完整复盘作为待办；观战者可选查看，不标待办。其他四款游戏的复盘均为可选查询，不标待办。
- 不自动打开复盘。本人关闭或确认复盘弹窗后才完成；同一局可再次查看但不重复标待办。完成状态按每局、每用户保存，刷新或重新入房后保持；新局重新计算。
- 完成记录以真实提交结果为准，不能仅保存在当前设备；打开弹窗、取消授权或提交失败均不算完成。中途重新开始不是正常终局，不新增必须先查看复盘的步骤。
- 狼人杀终局的房主待办依次为「昨夜信息 → 授权 → 本局复盘」。查看昨夜信息并关闭或确认后完成；授权成功且至少有一名玩家当前获授权才完成，取消或关闭不算。白天已有有效授权可沿用；全部撤回后授权重新成为待办。已经完成的终局复盘不会因重新授权而再次成为待办。
- 狼人杀入座玩家未获授权时，复盘仍是不可用的待办并说明等待房主授权；只授权其他人不会完成本人的待办。观战者不受座位授权限制，可选查看；授权控制入座玩家流程，并不保证其他人无法通过观战看到复盘。
- 狼人杀白天的昨夜信息、授权和复盘依次解锁，但本身不标待办，也不阻塞警长竞选。白天看过中途复盘不算终局完整复盘，房主和玩家终局仍各需查看一次。

### 狼人杀警长竞选

- 狼人杀白天的局势提示沿用房间主题；「白天 · 警长竞选」作为小字上下文，当前竞选阶段居中突出，提示依房主和玩家各自的状态变化。投票进度和倒计时另列，未投票座位在详情中查看。
- 警长竞选有详情时，手机和桌面均通过绿色「警长详情」牌打开居中弹窗，不再常驻桌面侧栏。详情不重复上方阶段标题和操作提示；报名结束前只说明公开记录尚未产生。
- 阿瓦隆与秘密希特勒在公开记录适用的阶段，用绿色「对局记录」牌打开居中弹窗；上方摘要只展示状态，不再充当入口。
- 保留原来的警长投票流程：底部「选择投票」打开同一详情面板，点击候选人或弃票即提交并显示选择，无需二次弹窗；揭晓前可改票。
- 阿瓦隆和秘密希特勒的投票点牌即提交；任务牌和政策牌点牌后须确认。投票揭晓前可改票，阿瓦隆任务揭晓前改牌也须再次确认；秘密希特勒政策确认后不可改。
- 房主结束报名、结束发言是对应阶段的待办；有资格且未提交的玩家「选择投票」是待办，提交选票或弃票后消失。投票关闭前可改票，但不产生新待办；平票新一轮重新判断。
- 「选择投票」入口标待办；进入投票后，候选人、弃票和确认等具体操作不重复标待办。
- 上警、取消报名、退水是可选行动，点击后各弹一次确认，取消不改变状态。删除旧阶段的房主「确认候选名单」操作，不删除玩家退水，也不为旧阶段保留该操作。
- 发言阶段的「自爆结束竞选」是需确认的危险操作，不标待办，不依赖昨夜信息或授权；执行后无警长，竞选待办消失。
- 狼人杀语音播报期间保持原有收起手牌体验，播报结束后再显示待办；等待播报不是用户待办。
- 阿瓦隆的夜晚确认可与播报并行；私密信息的展示和提交顺序依下文统一规则。

### 局中交互：五条统一规则

以下记录本次统一交互的设计决定。**需要玩家确认才能推进的私密步骤，由玩家点最后一个明确的「确定」或「知道了」，并由服务端接受后才推进。** 打开入口、选中座位、点「查看」、看到结果或点「取消」都不等于确认。公共结果按下方约定自动推进。

1. **在座位盘选技能目标。** 点行动牌进入选座，点满固定人数立即弹「取消／确定」，列明动作和座位。狼人袭击投票、预言家查验和机械狼学习选一个；魔术师交换、丘比特连人选两个。弹窗没有叉号，不靠遮罩或 Esc 退出。单目标取消后留在选座模式，可重新点目标；固定双目标取消后清空两个目标，仍留在选座模式。不开第二个底部确认入口。
2. **人数可变的技能和名单编辑。** 吹笛者可选一人或两人，也可跳过；选满不自动弹。主动点底部「确认催眠」才弹出名单，点「确定」才提交，点「取消」清空全部目标但留在选座模式。阿瓦隆组队不是瞄准技能：选满仍可改名单，之前确定的流程是点「提交队伍」提交，不在点满时弹窗。
3. **在专用面板投票或打牌。** 警长投票／弃票、阿瓦隆和秘密希特勒投票点选即提交。阿瓦隆任务牌及秘密希特勒政策牌点选后弹「取消／确定」，确定才提交；取消不提交，留在出牌面板。两款游戏的任务／政策面板在行动完成前不能关闭。
4. **把查看、登记和推进分开。** 主动打开的身份、词卡和指定私密状态先问「取消／查看」，点「查看」才亮内容。若此后还有待完成的确认，只留一个「知道了」或「确认信息」，不靠叉号、遮罩或 Esc 跳过。刚确认查验目标后直接返回的结果不用再问是否查看；需要等待阅读的结果，仍由看结果的人确认后推进。公开详情和纯回看不提交阶段操作。
5. **明确区分执行、放弃和取消。** 绘画笔画、实时猜词、抢图案直接生效；清空画布、重新开始、提前全部揭晓等不可逆操作保留一次明确确认。「取消」只是放弃本次弹窗里的提交，不等于弃票、撤回旧票或跳过。对同一动作不连弹两次确认。

### 已确认的特殊场景

- **狼人杀首夜**：狼人袭击、女巫、梦魇封锁、各角色查验及状态确认见[首夜角色交互矩阵](./NIGHT1_ROLE_ALIGNMENT_MATRIX.md#night-1-interaction-matrix)。
- **狼人杀全员状态**：情侣、表白、感染、转化和催眠均先问「取消／查看」，取消不亮内容、不登记，之后可再查看；亮出后点「知道了」才确认，所有应确认玩家完成后才满足推进条件。
- **种狼感染**：只能感染狼人投票结算出的袭击目标。点「感染」直接弹「确定对 X 号发动感染吗？」和「取消／确定」；取消不提交。「不用技能」是单独行动，确认后提交，可不查看目标直接放弃。没有可感染目标时保留锁住的感染牌，统一解释「本夜没有可感染的狼人袭击目标」，确认不用技能才推进。
- **身份与词卡**：狼人杀、阿瓦隆、秘密希特勒、瞎掰王首次看身份，以及谁是卧底首次看词卡，先问再亮，亮后只留「知道了」，点它才登记，登记成功才计入开局进度。不保留谁是卧底的「隐藏词卡」。回看也先问再亮；已登记的「知道了」只收起，不重复登记。
- **阿瓦隆夜间互认**：点入口先问是否查看，点「查看」才展示本人获准知道的信息，亮后只能点「确认信息」提交；不加展示后的二次询问，仍可与播报并行。
- **阿瓦隆湖仙**：沿用预言家的结果确认顺序。持有者点座位并确认查验，成功后立即私下看到「好人／坏人」，不再等被查验者确认展示，也不再问是否查看。持有者点「知道了」后，才转交湖仙并推进下一轮。
- **信息确认文案**：查看身份、词卡、私密状态、互认和政策预览后的确认统一使用「知道了」；执行行动的按钮仍使用具体动作名称。
- **秘密希特勒私密信息**：首夜互认和政策预览先问「取消／查看」，亮出后点「知道了」才提交。总统和总理的政策手牌自动显示给对应行动玩家，必须确认选牌或发起可用的否决请求，不能先关闭。否决被拒绝后，总理的同一手牌再次自动显示。
- **秘密希特勒总统行动**：提名总理与阿瓦隆共用选人弹窗：先公开并锁定预选，再在默认选中预选的最终提名中确认或换人；不合资格的玩家显示不能选的原因。调查、特别选举及处决在座位盘选人，选一人立即弹「取消／确定」；处决确认须提示不可撤销。调查确认后立即私下显示自由派或法西斯阵营，不揭示是否希特勒；点「知道了」才推进。删除局中调查结果回看牌，终局复盘保留调查记录。
- **公共投票和结果**：狼人杀警长竞选、阿瓦隆和秘密希特勒投票在全员投完后保留 5 秒揭晓倒计时，期间可改票；阿瓦隆任务出牌也保留 5 秒揭晓倒计时。揭晓后，警长竞选每轮结果、阿瓦隆投票与任务结果、秘密希特勒投票、政策与否决结果另展示 5 秒，再自动推进，不提供「知道了」或关闭操作。秘密希特勒触发混乱时，将投票或否决结果与自动施行的政策合并在一个结果面板中。
- **结果计时与面板优先级**：结果计时由服务端负责，掉线或机器人不阻塞；重连后显示剩余时间，错过的结果可在对局记录中查看。结果覆盖其他已打开的面板，结束后恢复原面板和未提交内容；决定胜负的结果完整展示后才进入终局。
- **警长竞选结果**：显示候选人的票数及投票者、弃票者和结论；无人报名、仅一人及自爆结束也展示结果。自爆中断的未结算选票不公开。
- **强制法案面板**：房主代入总统或总理机器人后，必须完成当前选牌或可用的否决操作才能离开或切换座位。
- **湖仙查验结果**：取消局中「查验结果」回看牌。持有人确认目标后立即私下看到阵营，点「知道了」才传递湖仙；未确认时重连仍显示结果。公开的查验对象记录和终局复盘保留。
- **希特勒当选获胜**：法西斯政策达到 3 张后，希特勒当选总理时，先展示政府投票通过结果 5 秒，然后进入终局画面揭晓获胜，不进入法案阶段。
- **秘密希特勒否决**：请求否决、同意否决和拒绝否决各自弹「取消／确定」；取消不提交。同意否决后展示未施行政策的结果 5 秒；若触发混乱则合并展示自动施行的政策。

### 待确认与核对

- 阿瓦隆和秘密希特勒各局中行动的具体待办入口仍需按真实规则逐项核对，不能把建议当成已确认决定。
- 私密查看类的其余入口还需逐项确认。区分主动翻开、行动直接返回结果和只读回看；不要把五条分类当成所有场景已逐项验收。
- 核对其他尚未逐项确认的直接提交是否有不同要求；不要从统一规则推断未确认的游戏行为。
- 对九款游戏继续核对每个阶段、动作、权限、阻塞原因、提交结果和确认文案；本表不是完整动作清单，也不代表已完成逐阶段验收。
- 极端屏幕空间不足时的固定信息区处理尚待看实际效果后决定，不把尚未选定的收起或内部滚动方式写成定案。

### 已确认规则的验收清单

以下是目标，不代表实现已经完成。逐游戏核对时，同时检查真实阶段、身份和权限、行动是否完成、前置关系、受阻原因及失败后的恢复；不得根据牌的文字、颜色或主次推断待办。

- **创建与发牌**：缺人时房主管理和分配角色仍标待办并解释原因；入座房主先看自己的身份，再提示主持开始。等待其他真人时，后续需要房主开始的游戏继续提示被阻塞的开始待办；黑死病只显示等待进度。
- **行动与选座**：多个角色行动选项归入角色子手牌，必要时入口标待办；单一行动直接显示。进入具体选择后不重复标记确认、取消、候选人或平等选项。座位选中不等于提交，失败时保留明确原因。
- **代打与异常**：待办跟随正在代打的机器人座位；等待机器人时只显示座位不泄露身份。准备失败需处理时，主持入口只显示一个待办，互斥解决方式不分别标记。
- **终局与授权**：五款身份游戏各自按本人完成状态显示复盘待办，刷新或重入后保持；观战者可选。狼人杀另核对昨夜信息、有效授权、复盘的顺序、撤销再授权及未获授权玩家的阻塞提示。
- **警长竞选**：分别核对报名、取消报名、退水的确认；结束报名与结束发言、投票与弃票、平票新轮和自爆结束竞选各自的待办和危险性，不让白天复盘流程阻塞竞选。
- **重新开始与奖励**：九款游戏核对局中和终局确认、实际清除内容、保留座位配置、只提醒房主本人待办及不直接发牌。两款接龙未进入揭晓不结算正常完成奖励；进入揭晓后已结算的奖励不会因重开撤销。
- **舞台与状态**：四款舞台游戏不新增玩法待办牌，玩家和房主都能使用进行中菜单；既有画布、编辑器和揭晓体验不变。座位房间核对固定信息、紧凑状态及不同玩家可见内容。

手牌统一为入口，不代表所有内容都以同一种形式打开。

| ---------------------------------- | ---------------------------------------------------------- |
| 手册、房主管理                     | 原位置切换为子手牌                                         |
| 玩法、笔记、提建议／修改建议       | 房间内居中弹窗；原有独立页面继续保留                       |
| 攻略、本局配置、查看建议、公开记录 | 各自的详情弹窗                                             |
| 房主修改配置                       | 房间内弹窗，原有独立页面继续保留                           |
| 音乐设置、个人设置                 | 房间内弹窗，原有独立页面继续保留                           |

| 选择行动目标                       | 座位保持可操作；固定人数选满弹确认，人数可变时主动打开确认 |

### 房间内弹窗与原有页面

- 房间留在原位，遮罩压暗背景，弹窗居中并四周留边。手机上给长内容足够空间，但不能看起来像换页。阅读弹窗的标题和右上角「关闭」固定，内容在弹窗内滚动；必须确认的弹窗依上文保留明确按钮，不共用阅读弹窗的关闭规则。
- 玩法保留完整内容。狼人杀笔记仅在白天和本局结束时显示入口，两阶段均可编辑并自动保存；保留座位记录、身份标记、投票记录及原有操作。软键盘打开时，当前输入仍可见。
- 建议编辑保留原有板型和角色选择，底部固定提交操作。关闭时若有未提交修改，先确认是否放弃；编辑期间发牌，保留弹窗与草稿，禁用提交并说明原因。查看建议继续支持按权限点赞、撤回和采纳。
- 房间手牌打开弹窗；原有独立页面的地址、布局、功能与返回行为保持不变。页面和弹窗展示相同的内容、笔记数据和提交规则，不各维护一份。验收时从房间入口与原有链接各走一遍。
- 弹窗打开期间游戏照常进行。轮到玩家行动时，不新增提示、不自动关闭或切换当前弹窗；必须确认的内容排队，关闭弹窗后仅展示仍有效的内容。关闭后回到原来的房间位置；从子手牌打开的弹窗关闭后停在主手牌。

## 公开记录

- 入口靠近对应局势，不藏进手册，不占一张额外的常驻行动牌。
- 警长竞选、任务轮次、政府选举等记录按各自的游戏结构组织。
- 默认优先看到当前或最近一轮，仍可回看先前内容。
- 查看记录与提交选票是不同操作，不在纯记录阅读中混入投票。
- 公开记录不等于揭示身份的本局复盘，二者名称和访问体验有明确区别。
- 秘密投票只展示允许公开的汇总；私人词语、身份、查验结果和秘密行动不因打开记录而泄露。
- 游戏结束后的额外揭示仍遵循该游戏规则，不把结束理解为所有内容都能无条件查看。

## 提示与反馈

- 公共阶段和整体进度归本局信息区。
- 上方按阶段标签、当前玩家的主要状态和必要说明组织；没有新信息的层级可以省略。
- 阶段保持公共一致，主状态按当前玩家展示其行动或等待，不泄露他人的私人身份和行动。进入选座时主状态改为选座指引，选中反馈靠近座位；提交失败时上方保留当前状态，错误留在操作附近。
- 需要等待播报才能行动的阶段，上方优先提示听播报；播报结束后再切换为当前行动提示，不提前暴露私人行动。各游戏仍按自己的播报与行动规则决定是否需要等待。
- 座位房间的状态、进度及公开摘要放在座位上方，不再堆在手牌上方；个人提示仍只按当前玩家的权限展示。
- 与某个玩家有关的行动、选中或允许公开的提交状态，靠近对应座位。
- 选择目标、提交中、操作失败等反馈靠近当前操作，不在上方、手牌、弹窗重复显示同一句话。
- 选中目标不等于提交；需要确认的行动保留明确确认与取消。
- 已有明确确认的操作不再叠加弹窗。直接操作（如点选题目、接龙准备／继续编辑）不因分类而自动增加确认。重新开始、处决等需要独立确认的操作保留确认；阶段结束后不继续显示已失效的确认。
- 不可执行的手牌明确标识状态；原因不常驻手牌上方，点击时说明当前原因，不执行游戏操作。
- 等待他人时，提示弱化，不持续抢占注意力。
- 失败、断线和未解决的问题清楚可见，不只闪一下就消失，也不只用颜色表达。
- 复制成功等轻回执可以短暂出现；关键游戏结果、必须确认的内容不能只靠短暂提示传达。
