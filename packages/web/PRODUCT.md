# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People playing party games together in person, including hosts and participants.

## Product Purpose

Help groups run multiple games by handling game rules, room state, and the information each
participant needs.

## Operating Context

Players use the web client in browsers and in the WeChat mini-program web-view, often on phones
while gathered together.

## Capabilities and Constraints

- Hosts and participants use shared rooms across multiple games.
- Visual changes must preserve game rules, content, and existing interaction flows.
- The client must remain usable in browsers and the WeChat mini-program web-view.

## Product Principles

- Make the current task and game state easy to understand.
- Support both hosts and participants throughout a game.
- Preserve the reliability of existing game and room interactions.
